Luminescence Engine

API reference for the LÖVE 11.5 tactical RPG engine, styled after Sega's Shining Force series.

LÖVE 11.5 Lua 5.1 GNU GPLv3 Preliminary

Anim

Anim.lua — global table

Loads texture atlases and creates looping frame-based animations.

Functions

Anim.loadStrip(imagePath: string, frameWidth: integer) → AnimFrameData

Loads a single-row horizontal strip atlas, dividing it into equal-width columns.

Anim.loadMultistrip(imagePath: string, frameWidth: integer, frameHeight: integer) → AnimFrameData[]

Loads a multi-row strip atlas; each row is returned as a separate AnimFrameData.

Anim.loadMatrix(imagePath: string, frameWidth: integer, frameHeight: integer) → AnimFrameData

Loads a grid atlas with frames ordered left-to-right, top-to-bottom.

Anim.new(frameData, x, y, frameDuration?) → Animation

Creates a looping animation. frameDuration defaults to 1.

Animation Object

MemberTypeDescription
imagelove.ImageSource texture
frameslove.Quad[]Animation frame quads
frameDurationnumberSeconds per frame
currentFrameintegerActive frame index
currentTimenumberElapsed time since last frame change
:update(dt)methodAdvance animation by dt seconds
:draw(x, y)methodRender current frame at pixel position

Battle

Battle.lua — global table

Manages the turn-based battle system, including turn order, movement, and combat resolution.

Properties

PropertyTypeDescription
Battle.activebooleanWhether a battle is currently running
Battle.combattantstableArray of combatants in the current battle
Battle.turntableFields: unit, startingPosition

Methods

Battle:initiate(combattants: table)

Initialises a battle. Sets each unit's moveTimer to their stats.agility.

Battle:nextTurn() → combatant

Selects the next unit to act based on the lowest moveTimer.

Battle:initiateTurn(unit)

Called at the start of a unit's turn. Moves the cursor to tile (1, 1).

Battle:attack(attacker, defender)

Resolves an attack. Damage = attacker.stats.attack − defender.stats.defense. Removes defender if HP reaches 0 and shows a dialog.

Methods

Push a handler set. The set may define key(key), gamepad(joystick, button), and realtime(dt).

Pop the top handler set.

Input:top() → Handlers | nil

Return the currently active handler set.

Game and map initialisation module. Entry point for loading adventure and battle maps.

Database Format

database/characters/*.lua & database/items/*.lua

Each file returns a plain Lua table and is indexed automatically by DB.

Character

-- database/characters/Alan.lua
return {
    name       = "Alan",
    class      = "swordsman",
    image      = "path/to/sprite.png",
    stats      = { level, hpmax, mpmax, attack, defense, agility, movement, exp, toNext },
    gain       = { { level_up_bonuses }, ... },
    promotion  = { class = "new_class", { promotion_stats }, ... },
    inventory  = { { "item_name", equipped = true }, ... },
}

Item

-- database/items/short sword.lua
return {
    name        = "short sword",
    description = "A basic blade.",
    icon        = "path/to/icon",
    consumable  = false,
    equipment   = {
        classes = { "swordsman" },
        type    = "weapon",   -- "weapon" | "armor" | "accessory"
        attack  = 2,
        bonus   = { hp, mp, attack, defense, agility, movement },
    },
    effect = {},
    range  = 0,
}
